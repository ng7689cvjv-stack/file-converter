# Lincoln Harbor Guest Map

Distribution map for the event at Lincoln Harbor Park, Weehawken Township, NJ (October 1, 2026).

## Files

- `lincoln-harbor-guest-map.svg` — master vector file (780 x 1092, a 5:7 ratio; prints cleanly at 5x7 in or scales up)
- `lincoln-harbor-guest-map.png` — 1560 x 2184 raster export

## Contents

- Tent complex in Lincoln Harbor Park, scaled from the David Monn tent dimension plan (80 x 130 ft main tent, 30 x 60 ft catering tent, south entry walkway)
- Valet badge and callout at the park entrance, 1600 Harbor Blvd
- Walking path from the ferry landing along the waterfront to the tent entry
- NY Waterway ferry landing and route to West 39th St, Hudson-Bergen Light Rail with Lincoln Harbor Station, Sheraton Hotel, Whole Foods, Route 495 with the Lincoln Tunnel portal
- Map key, Getting There panel, north arrow, not-to-scale note, OpenStreetMap attribution

## Production notes

- Typefaces load from Google Fonts (Pinyon Script, Cormorant Garamond). For print production, install the fonts locally or convert text to outlines before export.
- Geography is illustrative (based on OpenStreetMap data), deliberately not to scale so the park and tent read clearly.
